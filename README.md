# Seka — Telegram Mini App

Интерактивный адаптивный прототип карточной игры «Сека» для Telegram Mini App.

## Открыть приложение

- GitHub Pages: `https://opasi2222-dev.github.io/seka/app/`
- Файл для публикации: `app/index.html`
- Редактируемый исходный фрагмент: `src/seka-mini-app.fragment.html`

## Что реализовано в прототипе

- главная страница со списком и фильтрами столов;
- игровой стол на 2–8 игроков и сценарий раздачи по правилам «Секи»;
- кошелёк с разделами «Купить», «Продать», «Сделки»;
- P2P-очередь: покупатель видит один первый ордер, покупка лотами по 5 000 фишек;
- продавец создаёт ордер на сумму, кратную 5 000, и указывает номер для оплаты;
- профиль, история партий, друзья;
- админ-панель: игроки, столы, игры, P2P, обращения и статистика;
- Telegram BackButton, safe area и адаптация под портретный/альбомный экран телефона;
- русская локализация, плавные анимации и раздельные зоны карт, фишек и элементов управления.

## Как редактировать

1. Меняйте `src/seka-mini-app.fragment.html`.
2. После проверки обновляйте автономную версию `app/index.html`.
3. Коммиты в `main` автоматически обновляют GitHub Pages, если публикация настроена из корня ветки `main`.

Текущая версия — визуальный фронтенд-прототип с демонстрационными данными. Для реального продукта потребуется backend, проверка Telegram `initData`, WebSocket-сервер игры, база данных, авторизация админов и аудит P2P-операций.
